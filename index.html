Selected work

Three projects, end to end

01 · Analytics & BI

Credit card portfolio analytics & data quality automation

A pipeline and reporting layer for about 5 million daily card transactions, where reports were manual and data quality was hard to prove.

AWS GluePySparkRedshiftSQLPower BIIAM
Transactions→Glue + PySpark→Redshift→Power BI

Problem

Card data arrived at high volume, reporting depended on manual work, and nobody could show which numbers had been checked.

What I built

  • Automated ETL with Glue, Python, and PySpark into Redshift for SQL analytics.
  • Data quality validation, transaction reconciliation, metadata, lineage notes, and IAM-based access control.
  • Power BI dashboards for utilization, spending, payments, and delinquency.

Design targets

40% less manual reporting, 30% faster pipeline runs, 99.5% data quality pass rate.

02 · Data engineering

Healthcare data platform

A tested, governed data platform for claims, members, providers, and pharmacy data, built on synthetic data so every layer can be inspected.

PythondbtSnowflakepytestGitHub ActionsSQL
View the repository →
Payer feeds→Loader→dbt→Metrics layer→AI agent

Problem

Healthcare feeds change shape and arrive dirty. A platform has to catch that before analysts or an AI tool see it.

What I built

  • Idempotent loads, source data contracts, schema-drift flags, and quarantined bad rows.
  • A governed metrics layer, with Snowflake role-based access and masking.
  • An AI query agent with SQL guardrails and PHI redaction.

Result

60+ dbt tests and 32 pytest tests run in CI on every change.

03 · AI & GenAI

GenAI credit card policy & risk knowledge assistant

A retrieval-based assistant that answers policy and fraud questions from the source documents, with a way to measure whether the answers are any good.

PythonLangChainPineconeOpenAIRAGStreamlit
Policy PDFs→Chunks + embeddings→Pinecone→LangChain + OpenAI→Answer

Problem

Policy and risk questions meant searching long PDFs by hand, and a plain chatbot would answer without showing where it got the answer.

What I built

  • Ingestion with text extraction, overlapping chunks, and embeddings stored in Pinecone.
  • LangChain retrieval with an OpenAI model, so answers stay tied to the source policy.
  • A Streamlit app for multi-PDF upload and plain-language questions.

How it's measured

An evaluation framework for retrieval relevance, grounded accuracy, and latency.

More on GitHub, including AI-Driven Demand Forecasting, a Temporal Fusion Transformer and PPO agent with forecast error 10% below a statistical baseline.
